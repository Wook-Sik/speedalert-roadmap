# speedalert-roadmap

SpeedAlert(개인용 Android 과속 단속 안내 앱)가 내려받는 **지도 데이터**입니다. 앱 코드는 이 저장소에 없습니다.
이 저장소의 파일은 도구가 2주마다 자동으로 만들어 올립니다. 직접 수정하지 마세요.

## 내용
전국 도로(OSM의 모든 `highway`)와 알림 대상 무인 단속 카메라를 0.05° 타일로 나눈 데이터입니다.
카메라는 가장 가까운 도로에 스냅되어 있고, 카메라마다 진행 방향별 접근 경로(상류 약 1.5km)가 들어 있습니다.

| 경로 | 설명 |
|---|---|
| `latest.json` | 앱이 가장 먼저 읽는 작은 파일. 최신 버전, 태그, 패치 목록 |
| `manifest.json` | 버전, 격자, 타일별 해시·크기 |
| `sections.json` | 짝이 확정된 구간단속 |
| `t/<ix>/<iy>.sat` | 타일(gzip) |
| `p/<이전>__<새>/<ix>/<iy>.sap` | 바뀐 타일의 way 단위 패치(gzip). 통째로 받는 것보다 작을 때만 있음 |
| `changes/<이전>__<새>.json` | 추가·변경·삭제 타일과 받을 용량 |

앱은 `latest.json`이 가리키는 **태그**(`v<버전>`)의 파일만 받습니다. 그래서 갱신 도중에도 일관된 상태만 보입니다.
저장소가 커지면 이력을 새로 시작하므로 옛 태그는 사라질 수 있습니다.
